# m-explore-ros2

ROS2 package port for multi-robot autonomous exploration of [m-explore](https://github.com/hrnr/m-explore).

This repository was forked from [this one](https://github.com/robo-friends/m-explore-ros2) by [Rui P. Rocha](mailto:rprocha@isr.uc.pt) on Mar. 29, 2025, to compile without errors in *ROS Jazzy* distro.

### ROS packages included

- `explore_lite`
- `multirobot_map_merge`
